Kamus Gerbang Dasar (Lengkap)

AND A • B

Output 1 HANYA JIKA semua input bernilai 1.

OR A + B

Output 1 JIKA ada minimal satu input bernilai 1.

NOT !A

Pembalik (Inverter). Input 1 jadi 0, input 0 jadi 1.

NAND !(A • B)

NOT AND. Output 0 HANYA JIKA semua input 1.

NOR !(A + B)

NOT OR. Output 1 HANYA JIKA semua input 0.

XOR A ⊕ B

Exclusive OR. Output 1 HANYA JIKA kedua input BERBEDA.

XNOR A ⊙ B

Exclusive NOR. Output 1 HANYA JIKA kedua input SAMA.
